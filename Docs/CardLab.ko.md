# 카드 실험실 — 최종 45종 기준

현재 기준은 `Docs/Pilgrimage_Game_Design_2026-11-15_Final.md`입니다. 전체 규칙·정책·검증 결과는 [최종 통합 밸런스 보고서](FinalBalance_2026-11-15.ko.md)를 확인하세요.

## 실행

1. Unity에서 Play를 중지하고 컴파일을 기다립니다.
2. **Pilgrimage → v2 데모 열기 → Play** 후 교단을 선택합니다.
3. 화면 상단 **카드 실험**을 누릅니다. 별도 실험 게임이 생성되고 정규 게임은 보관됩니다.
4. 카드 이름을 검색해 **손패 +1**, 또는 **5장 선택 → 선택한 5장으로 구성**을 사용합니다. 같은 카드를 중복 선택할 수 있습니다.
5. **필드로 닫기** 후 더블클릭/Enter로 사용합니다. 방향키, Hover, 우클릭/Space 상세보기는 기존대로입니다.
6. **정규 게임 복귀**로 돌아옵니다. 단순히 필터를 닫는 것은 실험 모드 종료가 아닙니다.

도구는 Unity Editor/Development Build 전용입니다. 일반 Release Build에는 실험 진입 버튼이 없습니다. 실제 게임에서 필요한 카드 대상 선택 UI는 일반 빌드에도 제공합니다.

## 정규 게임과의 차이

- 정규 시작 헌금은 5, 기본 손패는 4장입니다.
- 실험 세션은 교단별 헌금 **100**, 신앙/교리 50, 공용 무신론자 100입니다. 각 교단 덱에 신도 **2장을 추가**해 대상을 마련합니다.
- 실험실의 5장 프리셋은 테스트 기능이며 정규 드로우 규칙을 바꾸지 않습니다.
- 실험실에서는 선택한 교단과 무관하게 모든 교단 카드를 검증할 수 있습니다.
- 명시적으로 추가한 인원은 `DebugPopulationDelta`로 따로 추적합니다. 실험 인원 합계를 정규 게임의 120명 검증과 혼동하지 마세요.
- 정규 게임의 카드·자원·라운드·지속 효과는 실험으로 변경되지 않습니다. 실험 손패 교체는 기존 카드를 버린 더미로 이동하고 새 실험 카드만 생성합니다.
- 실험실의 AI 자동 진행은 정지합니다. **다음 내 차례로**는 남은 행동을 종료하고 보상 결과를 확인해 다음 인간 턴으로 이동하는 수동 도구입니다.

## 도구

| 기능 | 조작 |
|---|---|
| 전체 45종 | 이름 검색, 실제 비용/현재 사용 여부 확인 |
| 원하는 손패 | 손패 +1 또는 특정 5장 구성 |
| 기본 행동 묶음 | 요청한 행동 카드 5장: 포교·포고령·설파·신앙의 결속·공격적 선교 |
| 사용 불가 확인 | 신도 5장. 신도·신실한 신도는 계속 드로우 가능/사용 불가 |
| 자원/상태 수정 | 편집할 교단 변경 → 헌금/신앙/교리 → 자원 적용 |

## 카드 대상 선택

포고령은 **헌금 20**, 자기 손패·덱·버린 더미에서 최대 2장입니다. 카드를 클릭하면 선택 강조가 바뀝니다. **선택 확정**으로 한 번만 비용을 지불합니다. 취소/ESC는 무료입니다. 신도/이단 제거 시 실제 제거 인원마다 무신론자가 1 증가합니다.

털가죽 집회는 **헌금 40**, 자기 손패 또는 덱 위쪽의 신도 1장을 같은 UI에서 선택합니다. 해당 카드가 신실한 신도로 바뀌고 상대 전체 신앙/교리가 20 감소합니다.

신실한 신도는 제거·변환·강탈할 수 없습니다. 자기 손패로 이동하는 축복은 가능합니다. 포고령은 사용하는 자기 자신과 다른 교단의 카드를 제거할 수 없습니다. 선택 확정 시 영역·소유·보호·비용을 다시 검사합니다.

## 다섯 행동 카드 순서 예시

청빈 선택, 기본 대상 순금(신앙 50), 포고령은 신도 이외 카드를 제거하는 예시입니다.

| 카드 | 비용과 변화 |
|---|---|
| 포교 | -8, 무신론자 -2, 신도 +2, 신앙 -2 |
| 포고령 | -20, 선택한 최대 2장 제거 |
| 설파 | -7, 교리 +10, 포교 1장 덱 추가 |
| 신앙의 결속 | 비용 0, 신도 1장을 대상 덱 아래로 이동, 신앙/교리 +15 |
| 공격적 선교 | 대상 신앙 50이면 -5, 대상 덱 신도 1장 강탈 |

헌금은 100→60, 신앙은 50→63, 교리는 50→75입니다. 대상 신앙을 30으로 바꾸면 선교 기본 비용이 3으로 바뀌어 헌금은 62입니다. 자신의 신앙이 21~30이면 추가 비용 1, 20 이하면 선교/구휼을 사용할 수 없습니다.

## 새 효과 확인

- 면죄부: 헌금/재산 +10, 신앙/교리 -10, 덱 신도 1장 이단화. 같은 GUID 유지.
- 고행: 4회 후 헌금 20·능력치 10 지급. 투자: 2회 후 0~30.
- 누추한 성전: 능력치 +15, 다음 2회 수입 -3. 기본 수입 3이면 0으로 감소합니다.
- 리모델링: 재산 -2, 수입/감소 배율 2배. 대주교는 카드 감소만 방지합니다.
- 고리대금업: 자금 10 이상 필요, 실제 10 지급 후 다음 정산 최대 30 회수. 부족분을 생성하지 않습니다.
- 이단 심판: 상세보기에서 누적 성공 사용 횟수/실제 비용을 확인합니다. 대상 교리 30과 29를 비교하세요.
- 거부하는 신도: 사용하면 일반 신도로 되돌아갑니다. 미사용 상태로 만료하면 실제 털가죽 교단의 덱 아래로 이동합니다. 상세보기에서 남은 정산을 확인합니다.

위 기산·중첩·대출 부족분·대상 해석은 최종 보고서에 별도 정책으로 설명했습니다. 정규 무작위 보상은 이 라이브러리 선택과 별개이며, 실제 지급 결과/더미만 확인할 수 있습니다.

테스트는 **Window → General → Test Runner**에서 `Pilgrimage.Tests`의 EditMode/PlayMode를 실행합니다. 최종 결과와 XML/렌더링 경로는 최신 보고서를 확인하세요. Scene과 원래 카드 조작은 보존했습니다.
