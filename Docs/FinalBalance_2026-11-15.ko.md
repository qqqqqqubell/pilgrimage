# 2026-11-15 최종 통합 밸런스 적용

사용자가 2026-11-15 다시 제공하고 승인한 45종 카드 원문은 [최종 기획서](Pilgrimage_Game_Design_2026-11-15_Final.md)에 반영했습니다. 카드 설명·비용·실행 효과는 이 원문을 따릅니다. 원문에 없는 공통 시작 구성·수입·드로우·자연 감소·보상·승리는 기존 규칙을 유지합니다. [추가 변경점](Pilgrimage_Second_Balance_Diff.md)은 대조에만 사용했습니다. 중간 패치를 순차 적용하지 않았습니다. 실제 작업 시작 카탈로그는 43종이 아니라 38종이었으므로 최종 45종으로 바로 갱신했습니다.

기존 0~37 ID와 카드 GUID를 유지했습니다. 추가 7종은 38~44에 배치했습니다. 이단 심판관은 기존 `Inquisitor` ID 19를 재사용했습니다. 원문 Flavor Text·설명은 보존하고, `현금`은 코스트 데이터에서 헌금으로, `교리 접합성/적합성`은 기존 Doctrine 상태와 대조했습니다. 화면의 `교리 접합성`은 정합성으로 정규화합니다.

## 적용 규칙

| 항목 | 실제 처리 |
|---|---|
| 인원/기간 | 4개 교단, 40라운드, 선플레이어 좌석 순환 |
| 시작 헌금 | **5**. 첫 라운드에 기본 수입을 더해 8로 만들지 않음 |
| 이후 라운드 수입 | **3 + floor(신도 수/10)**. 신도 수는 손패·덱·버린 더미의 일반/신실한/거부하는 신도 합계 |
| 드로우 | 기본 **4장**, 덱 부족분만 버린 더미 재섞기로 보충 |
| 초기 덱 | 신도 5, 포교 3, 헌금 요구 3, 정기 예배 4: 총 15장 |
| 초기 능력치 | 신앙심/교리 정합성 각각 50, 범위 0~100 |
| 자연 감소 | 네 행동 턴을 모두 종료할 때 각 교단 신앙심/교리 **-2**. 대주교는 이 감소를 막지 않음 |
| 신앙심 ≤10 | 다음 드로우 -1 |
| 손패 이단 | 교리 수치와 무관하게 행동 종료 시 이단 1장마다 덱 위쪽 신도 최대 1장 이단화 |
| 교리 ≤20 | 라운드 시작 시 덱의 신도 1장 이단화 |
| 교리 ≤10 | 다음 드로우 -1. 신앙심 페널티와 별도로 합산되어 둘 다 해당하면 2장 드로우 |
| 신도류 | 신도·신실한 신도 드로우 허용/사용 불가 유지. 거부하는 신도는 명세대로 비용 5로 사용 가능 |
| 승리 | 40라운드 후 손패·덱·버린 더미의 신도 수 최댓값. 동률은 공동 승리 후보 목록으로 표시 |

공격적 선교 비용은 **대상** 신앙심 ≤30이면 3, 초과면 5입니다. 공격적 선교·빈민 구휼에 대한 자기 신앙심의 추가 비용과 사용 금지는 새 카드 원문에 없어 제거했습니다. 저교리 상태에서 손패 이단의 변환 수량을 2장으로 늘리던 조건도 제거했습니다. 라운드 시작 저교리 변환과 저능력치 드로우 감소는 별개의 공통 규칙으로 유지합니다.

주요 실제 효과:

- 포고령: 손패·덱·버린 더미에서 최대 2장 선택. 신도/이단 1장 제거마다 무신론자 1 증가. 선택 취소는 무료, 확정 시 한 번만 비용 지불.
- 신앙의 결속: 자신의 덱 신도 1장을 대상 덱 아래로 이동, 신앙/교리 각각 +15.
- 고행: 사용 직후 지급하지 않고 4회 정산 뒤 헌금 +20 및 신앙/교리 +10.
- 대상단 투자: 2회 정산 뒤 0~30 양 끝값을 포함한 무작위 헌금.
- 마녀사냥: 신도 1장 이단화 및 헌금 +20.
- 헌금 요구: 헌금 +5, 신앙/교리 -5. 공의회: 교리 +25. 십일조: 헌금 +3, 재산 +5. 이자: 재산의 25%를 소수점 버림하여 지급하며 행동 턴당 1장.
- 면죄부: 헌금 +40, 재산 +30, 신앙/교리 -5, 덱 위쪽 신도 **1장** 이단화. 기존 전용 핸들러와 원본 GUID·덱 위치 보존 유지.
- 리모델링: 재산 -5, 2회 라운드 수입 ×2. 카드/자연 능력치 감소량을 늘리지 않습니다.
- 고리대금업: 헌금 10을 실제로 지급한 뒤 다음 정산에 대상에게서 최대 40 회수. 이자 1장을 실제 덱에 생성해 섞음. 부족한 헌금을 새로 만들지 않음.
- 대규모 선동: 자신 제외 각 교단 덱 아래에서 조작 가능한 신도 1장씩 자신의 덱 맨 위로 이동. 신실한 신도는 건너뛰며 같은 객체와 GUID를 보존합니다. 상대 신앙/교리는 감소하지 않습니다.
- 이단 심판: 기본 정책은 이번 사용 전 교단 누적 성공 횟수. 대상 교리를 항상 10+횟수×5 감소시킨 뒤 실제 결과가 30 미만이면 덱 위쪽 신도를 최대 2+횟수 제거하고 실제 제거 인원만큼 무신론자 증가. 대주교의 카드 감소 보호를 먼저 적용한 결과로 분기합니다. 덱에 새 심판 카드 1장 추가·셔플. 실패한 사용은 횟수/비용/복제 모두 없음.
- 이단 심판관: 자기 손패와 덱의 이단 전부를 신도로 변환. 버린 더미는 제외합니다.
- 털가죽의 부름: 대상 손패 또는 덱 위쪽 신도 합계 최대 2장을 거부하는 신도로 변환. 기본 자동 선택은 손패 우선이며 남은 수만큼 덱 위에서 찾습니다. `EffectTarget.Cards`를 제공하면 손패 또는 덱 위쪽 조작 가능한 신도 2장 중 원하는 최대 2장을 선택할 수 있습니다.
- 거부하는 신도: 신도로 집계. 사용 시 같은 객체를 신도로 변환해 버린 더미로 이동. 만료 시 같은 GUID로 신실한 신도가 되어 실제 털가죽 교단 좌석의 덱 아래로 이동.
- 지역 정화: 자신 포함 모두 신앙/교리 -30.
- 털가죽 집회: 자기 손패 또는 덱 위쪽 신도 1장을 선택해 신실한 신도로 변환, 자신 제외 모두 신앙/교리 -20. 대상 선택 UI 사용.
- 깊은 숲: 손패·덱의 신실한 신도 4장당 신앙 +8. 야성의 포효는 신앙 ≥40, 무신론자 3명을 이단 3장으로 바꾸어 상대 덱 위에 배치.

대주교는 위 카드에 의한 감소를 차단하고 증가를 허용합니다. 축복/빈민 구휼의 ‘최대’ 수량은 부분 처리와 0장 처리를 허용합니다. 회복 카드는 신도 수를 새로 만들어내지 않고 동일한 이단 객체를 변환합니다.

## 무작위 보상

- 4·12·20·28·36: 일반 카드 20종 중 각 교단 독립 무작위 1장.
- 8·16·24·32·40: 자기 전용 카드 중 신실한/거부하는 신도 제외. 청빈 4종, 순금 6종, 절대 교율 6종, 털가죽 5종.
- 라운드 종료 시 **네 교단에 이미 지급**합니다. 별도 시드 난수열을 사용하고 복원 추출합니다. 같은 카드가 여러 교단에 나올 수 있습니다.
- UI는 교단·실제 카드·실제 이동 더미를 보여주며 **획득 확인 · 계속** 버튼만 제공합니다. 확인으로 카드를 고르거나 다시 뽑지 않습니다.
- 기본 획득 위치는 기존 정책인 **버린 더미**입니다. 엔진의 `RoundRewardResult`는 생성 GUID와 위치를 기록합니다. 이후 실제 재섞기/드로우로 손패에 들어옵니다.
- 인간과 AI 모두 동일 엔진 추첨입니다. AI의 보상 선택 함수와 이전 선택 API는 제거했습니다. 내부 `RewardChoice` enum 이름만 기존 코드 호환을 위해 결과 확인 단계로 재사용합니다.
- 실험실의 카드 라이브러리 직접 선택/5장 프리셋은 유지합니다. 이는 정규 획득 규칙을 바꾸지 않습니다.

## 인원 보존과 승리

일반 게임의 `PopulationTotal`은 활성 손패·덱·버린 더미의 신도류 + 이단 + 공용 무신론자이며 항상 **120**이어야 합니다.

포교/포효는 실제 무신론자가 충분할 때만 생성합니다. 포고령·공개 비난·이단 심판은 실제 제거한 인원만 무신론자로 환원합니다. 모든 변환·강탈·거부하는 신도 만료는 같은 객체/GUID를 사용합니다. 제거된 객체는 Removed에서 추적하되 현재 인구에 중복 합산하지 않습니다. 무작위 보상은 인원 카드를 지급하지 않습니다.

실험실의 명시적 신도/이단 추가는 일반 규칙이 아닌 테스트 조작입니다. `DebugPopulationDelta`로 추가분을 별도 기록하고 `PopulationIsConserved`는 실험 인원까지 대조합니다. 이를 일반 게임이 120명이라는 증거로 혼용하지 않습니다. 일반 AI 40라운드 검사는 인원 추가 없이 매 행동/라운드에 120명을 검사합니다.

40라운드 마지막 보상 결과 확인 후 실제 신도 수로 승리 목록을 계산하고 화면에 승리 교단·최다 신도·전체 인원을 표시합니다. 동률 우선순위는 명세가 없어 공동 승리 목록을 사용합니다.

## 기획 미확정 사항과 정책

| 항목 | 현재 임시 정책 |
|---|---|
| 턴 기산 | 지연/지속은 다음 라운드 시작 정산을 1회로 계산. 수입형은 N번째 정산 후 만료 |
| 정산 순서 | 거부하는 신도 만료 → 예약 일반 보상 → 저교리 이단화 → 전원 수입 → 대출 회수 → 지속 만료 → 드로우 |
| 복수 대출 | 기본은 새 라운드 선플레이어 순 회수. `loansResolveInLeaderOrder=false`로 좌석 순 설정 가능 |
| 대출 부족분 | 기본은 현재 실제 헌금까지만 회수하고 부족분 종료. `loanShortfall=CarryRemainder`이면 잔여 채무만 다음 정산에 보류 |
| 심판 횟수 | 기본은 교단 누적 성공 사용, 이번 사용 전 횟수. `judgmentCountScope=PhysicalCard`, `judgmentIncludesCurrentUse`로 별도 정책 가능 |
| 심판 분기 교리 | 대상 교단의 교리 감소 처리 후 실제 수치가 30 미만인지 검사 |
| 심판 신도 부족 | 기본은 가능한 인원만 제거·환원. `judgmentRequiresFullFollowers=true`이면 충분한 인원 요구 |
| 거부하는 신도 | 어느 더미에 있어도 변환된 라운드의 R+3 시작에 만료. 이동해도 타이머 재시작 없음. 소유자 행동 기회가 세 번 보장되는 방식은 아님 |
| 털가죽의 부름 | 손패 우선, 덱 위쪽으로 보충하여 합계 최대 2장. 기존 `furCallConvertsAllHandFollowers` 직렬화 필드는 호환용으로 남지만 효과 수량에는 관여하지 않음 |
| 덱 위쪽 신도 | 위에서부터 첫 해당 신도를 검색. 맨 위 물리 카드가 신도가 아니면 실패하는 해석은 채택하지 않음 |
| 마녀사냥 | 기본 자기 덱 위쪽 신도. 기존 `witchHuntSource`로 자기 손패 정책 가능 |
| 리모델링 자연 감소 | 리모델링은 능력치 감소 배율을 등록하지 않음. 자연 감소는 기본 -2이며 대주교로 차단되지 않음. 이전 배율 정책 필드는 직렬화 호환을 위해 유지 |
| 중첩/수입 연산 | 기존 독립 중첩, 증감 후 배율·최종 버림·최저 수입 0 유지. 같은 종류 갱신/배율 후 증감 옵션도 유지 |
| 보상 위치 | 기본 Discard. 여전히 별도 `rewardDestination` 정책 |
| 자기 대상 | 기존 `allowSelfAsOpponentTarget=false` 유지. 원문에 자기 허용/금지가 명확하지 않음 |
| 정해진 수량 부족 | 기존 `requireFullFollowerTargets=true`가 면죄부 1장·결속 1장·선교 1장·공개 비난 1장·추수꾼 2장에 적용됨. ‘최대’ 카드와 심판은 위 별도 정책을 사용 |
| 사용 중인 카드 | 즉시 Discard, 중앙 공개는 표시 참조. 현재 사용하는 자기 카드는 포고령 대상에서 제외 |
| 40라운드 이후 | 추가 정산 없음. 미도래 예약·대출은 기록만 남고 지급/회수하지 않음 |

원문에서 수량 조건이 명시된 포교의 무신론자 2명, 털갈이 의식의 덱 신도 2장, 희망의 헌금 ≤10, 고리대금업의 헌금 ≥10 등은 임시 정책과 구분해 엔진에서 검증합니다. 이전 `rejectWhenAtheistsInsufficient=false` 설정으로 최종 인원 보존 규칙을 우회하지 않습니다. 이전 설정 자산의 시작 헌금 값도 정규 시작 헌금 5를 덮어쓰지 않습니다.

## AI

라운드 실제 수입 3+신도 보너스, 새로운 비용, 원문 조건과 보호/감소 배율을 읽습니다. 공개 상대 상태만 사용하고 비공개 손패·덱 순서는 평가기에 전달하지 않습니다. 유효 대상 전체를 공통 `CanPlay`로 검사한 후 선택하며 공개 직전/실행 시에도 재검증합니다.

새 경제 단위에 맞춰 헌금·비용 가중치를 낮추고, 신자·교리 유지·견제와 교단 특성 가중치를 유지/조정했습니다. `savingHorizon`, `savingPenalty`로 고비용 카드를 위한 저축, `resourceUnlockWeight`로 자원 카드가 유효 카드를 사용 가능하게 하는 가치, `thresholdCrossingValue`로 자연 감소 후 10/20/30 경계를 악화/회피하는 가치를 조절합니다. 이들은 게임 보상이나 경제 보너스가 아닌 평가 점수입니다.

신규 2종·대출·심판·부름·거부하는 신도도 평가합니다. 털가죽 AI는 자신의 거부하는 신도를 무조건 일반 신도로 되돌리지 않으며, 다른 교단은 잃을 신도를 구제하는 가치를 평가합니다. 자원이 부족하면 기다리거나 다른 카드를 사용하고, 후보가 없거나 전략 점수가 낮으면 종료합니다. 카드 점수를 일괄 양수로 만들지 않았습니다. 안전 상한과 실패 카드 재제출 방지, 기존 중앙 공개 애니메이션을 유지합니다.
