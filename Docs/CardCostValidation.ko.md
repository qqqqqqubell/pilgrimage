# 카드 코스트 표시 수정 및 검증 보고

후속 기능: 포고령 구현과 별도 실험 세션은 [카드 실험 안내](CardLab.ko.md)를 참조하세요. 이 보고서의 미구현 8종 중 포고령은 이후 구현되어 현재 미구현은 7종입니다.

기준: `Pilgrimage_Game_Design_2026-11-14.md`와 후속 사용자 지시. 신도·신실한 신도는 **사용 불가이며 코스트가 없는 카드**로 처리합니다. 이전의 ‘원문 미명시’ 표시는 제거했습니다. 코스트가 없다는 것은 0코스트 행동 카드와 다릅니다.

![신도류 코스트 표시를 제거한 실제 데모 화면](Images/PilgrimagePassiveCards.png)

## 데이터와 표시 분리

| CostKind | 의미 | 플레이어 표시 |
|---|---|---|
| None | 코스트 개념이 없는 카드. 신도·신실한 신도 | 앞면/상세/보상/도감에 코스트 줄을 만들지 않음 |
| Fixed | 명시된 정수 코스트. 0도 유효 | `헌금 0`, `헌금 1` 등 |
| Variable | 조건에 따라 달라지는 코스트. 공격적 선교 | `헌금 X`. 실제 비용은 기존 대상 조건으로 계산 |
| MissingSpecification | 실제 명세 누락 | 코스트를 만들어내지 않으며 사용 차단. 개발 검증에 기록 |

기존 로직 호환용 `Cost`의 음수 센티널은 유지했습니다. `FixedOfferingCost`는 Fixed에 대해서만 값을 반환하며, None/Variable/MissingSpecification은 null입니다. 실제 의미 구분은 `CostKind`로 수행합니다. None과 MissingSpecification은 데이터가 잘못 사용 가능으로 입력되어도 생성 시 사용을 차단합니다.

신도류 앞면에는 카드 이름, 안정적인 번호, 이미지 영역만 남깁니다. 상세에는 이름·원문 고유 효과·Flavor Text만 표시합니다. 코스트·대상·기본 사용 조건·구현 상태·실물 GUID 등은 표시하지 않습니다. 특히 신실한 신도의 변환·제거·강탈 보호 설명은 그대로 유지합니다.

`CardPresentation`이 플레이어용 표시를 담당합니다. 일반 카드의 필요한 비용·효과·조건은 유지하되 `원문 미명시`, `명세 대기`, `TODO`, 영문 구현 플래그, 기본값 ‘미정’, ‘원문에 추가 사용 조건 없음’ 문구는 표시하지 않습니다. 미구현/명세 부족 카드는 **현재 사용할 수 없습니다**로 안내하여 사용 가능한 것처럼 보이지 않게 합니다. 원본 설명과 진단 상태는 삭제하거나 대체하지 않습니다.

확인 범위: 손패 앞면, 상세보기, 전체 38종 도감, 보상 선택, 사용 실패 피드백, 기존 v1 테스트 화면의 코스트 줄.

## 실제 명세/구현 문제 기록

현재 38종 중 코스트 명세 누락은 **0종**입니다. 신도류 2종은 None으로 분류하며 누락으로 보고하지 않습니다. 공격적 선교는 명시된 X 조건이 있으므로 Variable입니다.

다음 8종의 구현/상세 규칙 문제는 그대로 남아 있으며 사용을 차단합니다.

| 카드 | 남은 문제 |
|---|---|
| 포고령 | 원하는 자기 손패/덱 카드 선택 명령 및 UI 미구현 |
| 고행 | 5턴 지연 큐와 턴 기산 미확정 |
| 고독한 성찰 | 다음 턴 수입 변경의 범위·순서 처리 |
| 대상단 투자 | 2턴 지연 및 지급 처리 미구현 |
| 마녀사냥 | 변환할 신도의 선택 영역이 원문에 명시되지 않음 |
| 누추한 성전 | 지속 수입 감소의 기산·중첩 처리 |
| 성전 리모델링 | 지속 배수·중첩·우선순위 처리 |
| 대주교 | 지속 보호의 기산·중첩·우선순위 처리 |

`CardPresentation.Diagnostics`가 명세 누락·미구현·표시에서 제외한 원본 문구를 기록합니다. Unity Editor 또는 Development Build에서 데모를 시작하면 Console의 **Pilgrimage 카드 검증 (개발 로그)**에 출력합니다. 합성 누락 카드 테스트로 실제 누락이 진단되고 사용 차단되는 것도 확인합니다. 원본 데이터에 남겨 둔 기본 안내 문구는 플레이어 화면에 보이지 않지만 진단에서 제외 내역을 확인할 수 있습니다.
