# 매커니즘

- 정해진 턴 수 내에 가장 많은 신자 수를 가지기

## 수치

- 신자: 최종 목표, 모든 라운드 종료 시 가장 많은 카드를 모은 사람이 승리.
- 헌금(코스트) → 카드 코스트 사용에 사용.
- 신앙심 → 수치가 낮을 경우 특정 카드에 대해 디메리트가 들어감, 최소치 0, 최대치 100.
- 교리 정합성 → 수치가 낮을 경우 특정 카드에 대해 디메리트가 들어감, 최소치 0, 최대치 100.

## 교단

- 빈민너무좋아교(**청빈의 사도단**)
- 돈너무좋아교(**순금의 형제단**)
- 교리너무좋아교(**절대 교율 교단**)
- 퍼리퍼리교(**털가죽 교단**)

## 문법

N 코스트 : 코스트 미정

X 코스트 : 변수조건 따라 달라짐

카드 효과 내  카드 이름이 들어가면 [] 안에

코스트는 이름 옆에 () 안에

설명은 이름, 코스트 옆에 : 쓰고 작성하기

### 시작 자원

- 라운드마다 받는 헌금: 5 헌금
- 라운드마다 드로우하는 카드 수: 5장
- 초기 신앙심: 50
- 초기 교리 적합성: 50
- 무신론자 수: 100명
- 초기 신도 수: 5명([신도] 5장)
- [포교] 4장
- [헌금 요구] 3장
- [정기 예배] 3장

### 라운드 진행

- 40라운드, 선플레이어부터 카드 효과가 발동하며, 라운드가 끝날때마다 선플레어어가 순서대로 바뀜.
- 라운드가 끝나면 모든 카드를 버리고 새로운 카드 5장을 뽑는다.
- 만약 이 과정에서 덱이 소진되면 버린 카드를 섞어서 마저 뽑는다.

### N라운드 종료(N = 4, 8, 12, …, 40)

- **k라운드(k = 4, 12, 20, … 36)마다** [신도]와 [이단]을 제외한 일반 카드 중 1장 획득.
- **K라운드(K = 8, 16, 24, … 40)마다** 자신의 교단 카드 중 1장 획득.

### AI 플레이어 설정

- 카드를 스스로 제출함. 제출하는 카드를 플레이어가 알 수 있도록 가운데에 사용한 카드 패를 놓으며 보여줌. 물론 갖고 있는 카드 여러 개를 쓸 수도 있음
- 카드를 여러 개 쓸 때는 딜레이를 두고 쓰어 무슨 카드를 썼는지 플레이어가 알 수 있도록 한다.

### 기본 게임 중 인터페이스

- 4명이 상하좌우에 배치되어 있음
- 각각이 들고 있는 카드 갯수가 나타나며, 상대의 카드는 흑백으로 표기되어 꺼내기 전까진 내용을 모름
- 각각의 헌금, 신도 수가 테이블 이라고 써져 있는 부분에 값으로 나타나 보여짐
- 내 테이블의 카드는 나에게 보여짐

### 카드 UX

- 기본적으로는 들고 있는 카드 n장이 겹쳐서 카드의 앞면이 보이게 나열되어 있음.
- 카드는 앞면, 뒷면이 존재한다. 앞면에는 카드를 나타내는 그림과 번호가 나타나있으며, 뒷면에는 카드의 효과와 사용해야되는 코스트 정보가 적혀있음.
- 마우스를 드래그해 내 카드에 갖다대면 카드가 살짝 튀어나오며, 형광으로 테두리가 빛남
- 카드를 우클릭하면 뒷면으로 전환하여, 카드의 효과 설명을 상세히 보여줌.
- 카드에 마우스를 드래그 한 뒤 두 번 좌클릭하여 카드를 사용할 수 있다. release하는 모션이 있다.
- 마우스 드래그 대신 키보드 좌우버튼을 활용해 낼 카드를 선택할 수도 있다. 스페이스 바를 누르면 카드를 뒤집어 정보를 보여주고(마우스 우클릭에 해당), 엔터를 눌러 카드를 낼 수 있다.
