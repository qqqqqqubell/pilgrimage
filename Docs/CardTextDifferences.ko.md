## 승인 당시 텍스트에 빠졌던 조건과 해석

- 공격적 선교·빈민 구휼: 자신의 신앙심이 21~30이면 비용 +1, 20 이하면 사용 불가. 제공한 텍스트에는 이 공통 페널티가 없습니다.
- 이단: 현재 교리가 30 이하면 행동 종료 시 손패 이단 1장당 덱 신도를 최대 2장 변환합니다. 제공한 카드 설명에는 기본 1장만 적혀 있습니다.
- 교단 간 고리대금업: 현재 대상이 가진 실제 헌금까지만 회수하고 부족분은 기본적으로 소멸합니다.
- 지연·지속 효과의 '턴'은 현재 다음 라운드 시작 정산 횟수로 처리합니다. 제공 텍스트는 기산 시점을 별도로 정의하지 않습니다.
- 현재 기본 정책과 프로젝트 설정으로 변경 가능한 항목을 구별했습니다. 실제 근거: `Assets/Scripts/Pilgrimage/Game/FinalBalanceRules.cs`, `SessionCardEffects.cs`, `TimedCardEffects.cs`, `Cards/CardCatalogData.cs`.

## 이미지 대응

- 일반 카드 텍스트의 1~22번은 앞면 이미지 0~21번에 순서대로 대응합니다.
- 뒷면 파일명 25~47은 순서가 뒤섞여 있습니다. 이미지 내부 번호/타로 이름을 기준으로 대응합니다.
- `이단 심문관.png`는 텍스트의 `이단 심판관`과 기존 `CardId.Inquisitor`에 연결합니다.
- `털가죽 집회` 앞면 파일은 제공된 두 번째 ZIP에 없습니다. 사용자 지시에 따라 카드 이름이 적힌 임시 앞면을 유지합니다.

승인 후 처리: 공격적 선교·빈민 구휼의 자기 신앙 페널티와 손패 이단의 저교리 추가 변환 수량을 제거했습니다. 고리대금업 회수액은 40이며, 부족분은 기존 기본 정책대로 현재 실제 보유 헌금까지만 회수합니다. 지연·지속의 턴 기산과 카드 원문에 없는 공통 게임 규칙은 유지했습니다.
